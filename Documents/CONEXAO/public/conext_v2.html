Conexbot WP

Plugin oficial — v1.0.3 — WordPress + WooCommerce
  • Sincronização automática de produtos WooCommerce (estoque, preços, variações)
  • Chat nativo flutuante no frontend via iframe seguro com contexto do usuário logado
  • Resposta automática a comentários via IA (hook nativo wp_insert_comment)
  • Detecção inteligente de canal: WordPress vs WhatsApp por email/telefone
  • Painel de configuração Token + Bot ID no WP Admin
  • Sincronização bidirecional: WP ↔ SaaS ↔ WP em tempo real assíncrono
