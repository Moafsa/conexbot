Modelo de cobrança — Agência → Cliente
💰 Plano Fixo
Agência cobra mensalidade fixa. Plataforma recebe split % sobre tudo que a agência faturar com o cliente.
Ex: R$800/mês → plataforma leva 15%
📈 Split por Resultado
Agência cobra % sobre as vendas geradas pelo bot/marketing para o cliente. Zero mensalidade.
Ex: 3% das vendas → plataforma leva tier %
🔀 Híbrido
Base fixa menor + % de performance. Mais flexível para fechar contratos com clientes conservadores.
Ex: R$300 + 1,5% vendas
